# 🐴 黑马记账

个人日常记账桌面应用，数据存储在本地，无需联网。

## 功能

- **记一笔**：记录金额、选择分类、填写日期和备注
- **两级分类**：一级大类 → 二级小类，先选大类再选小类
- **自定义分类**：可新增/修改/删除自己的分类，系统预设分类受保护
- **历史明细**：按时间倒序展示所有记录，支持按分类筛选
- **月度统计**：按月查看各分类支出合计
- **数据本地化**：所有数据存为 JSON 文件，离线可用

## 技术栈

| 层面 | 技术 |
|------|------|
| 桌面框架 | Electron |
| 前端 | React 18 + TypeScript |
| 后端 | Express 5 |
| 样式 | TailwindCSS |
| 构建 | Vite |
| 数据存储 | JSON 文件 |

## 项目结构

```
ledger/
├── electron/main.cjs       # Electron 主进程
├── server/
│   ├── index.ts            # Express API 服务
│   └── store.ts            # JSON 数据读写
├── src/renderer/
│   ├── App.tsx             # 主界面
│   ├── types.ts            # 类型定义 + API 封装
│   ├── main.tsx            # React 入口
│   └── index.css           # 全局样式
├── data/ledger.json        # 记账数据
└── package.json
```

## 快速开始

```bash
# 安装依赖（仅首次）
npm install

# 启动开发模式
npm run dev
```

启动后会自动打开 Electron 窗口。

## 分类体系

系统预置 9 个一级分类，每个下设若干二级分类：

| 一级分类 | 二级分类 |
|----------|----------|
| 🍽️ 餐饮 | 早餐、午餐、晚餐、零食、饮料、聚餐 |
| 🚗 交通 | 公交、地铁、出租车、加油、停车、火车飞机 |
| 🛍️ 购物 | 衣物、电子产品、日用品、化妆品、书籍 |
| 🏠 居住 | 房租、水电、物业、维修、家具 |
| 🎮 娱乐 | 电影、游戏、旅游、运动、KTV |
| 🏥 医疗 | 门诊、药品、体检、住院 |
| 📚 教育 | 学费、培训、书本、考试 |
| 💰 金融 | 保险、理财、贷款、手续费 |
| 📌 其他 | 礼品、捐赠、宠物、其他杂项 |

用户可在「设置」中新增自定义分类，也可在系统分类下添加自己的二级分类。
